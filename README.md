# MazeOnTerminal (C Version)

Windowsコンソール（コマンドプロンプト/PowerShell）上で動作する、C言語製の3D迷路探索ゲームです。
グラフィックライブラリを使用せず、標準ライブラリとWindows APIのみを用いて、ASCII文字によるリアルタイムレンダリングを実現しています。

## 特徴

* **グリッドベース・レイキャスティング**: `WriteConsoleOutputW` を使用した高速なコンソール描画。
* **自由配置オブジェクト**: 壁だけでなく、空間内に自由に配置された平面オブジェクト（ポータル）の描画。
* **プロシージャル表現**: 画像テクスチャを使用せず、数式による動的な模様生成。
* **画面遷移エフェクト**: ディゾルブ（溶解）演出によるシームレスなシーン遷移。

## 動作環境

* **OS**: Windows 10 / 11
* **コンパイラ**: GCC (MinGW) 等、Cコンパイラ
    * ※ `windows.h` を使用しているため、Windows環境必須です。

## コンパイルと実行方法

ソースコードは単一のコンパイルユニット（`main.c` から各ヘッダをインクルード）で構成されています。
以下のコマンドでコンパイルしてください。

```bash
gcc main.c -o maze.exe -O3
```

コンパイル後、生成された maze.exe を実行してください。

```bash
./maze.exe
```

## 操作方法
- W / A / S / D: 移動
- マウス移動: 視点操作
- Enter: ゲーム終了
